# Directory submissions: Materialicons (and Fluenticons)

Copy for submitting materialicons.co to the directories and newsletters that already link to
fluenticons.co. Submitting needs your accounts, so this is ready to paste rather than sent.
Confirm each site's current submission route before sending (links below are where to start;
some sites only take suggestions by email or contact form).

## The copy

**Name:** Materialicons

**URL:** https://materialicons.co/

**Tagline (60 chars):** Every Google Material Symbol as SVG, PNG, JSX and font code

**Short description (≤160 chars):** Free viewer for Google's 3,900+ Material Symbols. Search, preview any style and weight, and copy SVG, PNG, React, MUI, Flutter or Android code.

**Long description:**

Materialicons is a free, fast browser for Google's Material Symbols, the open-source icons
behind Android and Google's apps. Search 3,900+ icons by name, keyword or category, preview
each one in outlined, rounded and sharp styles at every weight, and copy it as SVG, PNG, an
HTML font ligature, React, Vue, Angular, MUI, Flutter, an Android vector drawable or a Power
Apps formula. Icon pages list the code point and, where they exist, the MUI import and the
matching Microsoft Fluent icon. No sign-up, no paywalled icons; the icons are Apache 2.0. It's the sister site of
Fluenticons (Microsoft's Fluent UI System Icons).

**Tags:** icons, material design, material symbols, google icons, svg, react, mui, flutter, design resources, free

**Screenshot:** the homepage with the grid and an icon open in the editor (1600×1000).

## Awesome-list entries

Open a pull request on each list, following its contributing guide (alphabetical order, one line,
no marketing words). Candidate lists to check first: `notlmn/awesome-icons`,
`sachin1092/awesome-material`, and design-resource lists that already include Fluenticons.

```md
- [Materialicons](https://materialicons.co/) - Browse Google's Material Symbols and copy them as SVG, PNG, React, MUI, Flutter or font code.
```

For a Fluent or Microsoft list:

```md
- [Fluenticons](https://fluenticons.co/) - Browse Microsoft's Fluent UI System Icons and copy them as SVG, PNG, React, Blazor or XAML code.
```
